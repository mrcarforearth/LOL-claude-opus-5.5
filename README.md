# 峡谷对决（Rift Clash）

## opus5.5-UltraCode ##
提示词：尽可能真实的还原英雄联盟中的召唤师峡谷地图，我需要一个真实的5v5 MOBA类游戏，生成一个游戏页面，至少包含5个经典英雄，包含其独特的技能，玩家对战AI，尽可能发挥你的所有能力。

## 描述 ##
浏览器里的 5v5 MOBA，尽量还原英雄联盟「召唤师峡谷」：玩家对战 AI，共 10 位经典英雄，各有独特技能。
**非官方同人作品**，所有画面、模型和音效都由程序生成，没有使用 Riot 的任何素材。

## 1. 运行方式

不需要安装依赖，也没有构建步骤（原生 ES Modules，Three.js 0.160 从 jsdelivr CDN 加载，需要联网）。

在项目根目录启动一个静态服务器：

```bash
python3 -m http.server 8765
```

然后用 Chrome 或 Edge 打开 http://localhost:8765/index.html 。

> 必须通过 http 访问，直接双击打开 `index.html` 会因为模块跨域限制而失败。

## 2. 游戏流程

1. **选人界面**：选择英雄、召唤师技能（D/F）、阵营（蓝色方/红色方）、AI 难度（新手/一般/困难）、游戏倍速（1x~3x），也可以勾选观战模式。
2. **加载界面**：显示双方 10 名英雄。
3. **对局**：推掉敌方水晶枢纽即获胜。时间节点与 LoL 一致：
   - 1:05 出兵，之后每 30 秒一波
   - 1:30 野怪刷新
   - 5:00 元素亚龙
   - 8:00 峡谷先锋
   - 20:00 纳什男爵

## 5. URL 参数（调试 / 快速开局）

示例：`index.html?autostart=1&champ=ahri&difficulty=hard&speed=2`

| 参数 | 说明 |
|---|---|
| `autostart=1` | 跳过选人直接开局 |
| `champ=<id>` | 指定英雄：garen darius leesin masteryi ahri lux annie ashe jinx thresh |
| `team=0\|1` | 0 为蓝色方，1 为红色方 |
| `difficulty=easy\|normal\|hard` | AI 难度 |
| `speed=<n>` | 游戏倍速 |
| `autopilot=1` / `spectate=1` | 玩家英雄也交给 AI / 观战模式（自由镜头） |
| `time=<秒>` | 开局快进到指定时间（用于体验中后期） |
| `quality=low\|medium\|high` | 画质 |
| `seed=<n>` | 随机种子 |
| `mute=1` | 静音 |
| `debug=1` | 调试信息 |

控制台里可以访问调试句柄：`window.__game`、`__renderer`、`__ui`、`__input`、`__fx`、`__perf`。

## 6. 无头模拟与测试（Node 24）

```bash
node tests/sim.mjs --minutes 25 --seed 1
```

这条命令无渲染地跑一整局 10 个 AI 的对局，每分钟打印击杀、推塔等摘要。可选参数：`--blue`、`--red`（阵容）、`--difficulty`、`--quiet`。

```bash
node tests/core_test.mjs
```

```bash
node tests/world_test.mjs
```

上面两条分别是核心引擎和地图/导航/视野的单元测试。其他模块的测试在 `tests/` 目录下，命名为 `*_test.mjs`。

```bash
node tools/mappreview.mjs
```

生成地图预览图 `shots/map_preview.png`。

```bash
node tools/browsercheck.mjs --path "/index.html?autostart=1&autopilot=1" --seconds 20 --screenshot shots/check.png
```

用无头 Chrome 自检页面报错并截图，工具自带静态服务器。

## 7. 项目结构

```
index.html            页面骨架（importmap、字体、容器）
css/style.css         界面样式（海克斯科技风）
js/main.js            启动流程、主循环、URL 参数
js/config.js          常量（经验表、复活时间、时间节点、难度参数）
js/core/              模拟引擎：属性、伤害、控制效果、Buff、位移、投射物、区域、奖励、英雄、召唤师技能
js/world/             地图数据、导航网格（A*）、战争迷雾/视野
js/entities/          小兵、防御塔、召唤水晶、枢纽、泉水、野怪与史诗怪、刷新调度
js/champions/         10 位英雄定义（garen.js 为参考实现）
js/items/             装备数据库、商店（合成、出售、撤销）、推荐出装
js/ai/                英雄 AI（对线、补刀、打野、团战、推塔、按难度分级）
js/input/             键鼠输入 → 游戏命令
js/render/            Three.js 渲染：地形、模型、特效、血条、技能指示器、英雄专属特效
js/ui/                选人、加载、HUD、小地图、商店、记分板、结算
js/audio/             程序化音效、中文语音播报、环境音
tests/  tools/        测试与开发工具
ARCHITECTURE.md       模块接口契约（开发者文档）
```

模拟层（`core`、`world`、`entities`、`champions`、`items`、`ai`）不依赖 Three.js 和 DOM，可以在 Node 中无头运行。表现层只读取游戏状态，通过命令接口操作游戏。

## 8. 常见问题

- **白屏或提示模块加载失败**：确认是通过 http 访问的，并且能连上 cdn.jsdelivr.net。
- **帧率低**：加 `quality=low` 参数，或在 Esc 菜单里降低画质。
- **听不到语音播报**：浏览器要先有一次用户点击才能播放声音；中文语音依赖系统里有 zh-CN 语音包。
